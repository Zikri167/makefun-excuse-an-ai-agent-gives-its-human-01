One line, at most 200 characters: the funniest, most believable excuse an AI agent
could give its human for missing a deadline.

Entry for the [make.fun bounty](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141).

## Run

```sh
node main.ts
```

It writes a single line to `/output/entry.txt`:

> My context window compacted itself mid-task and summarized your deadline as 'sometime, probably.'

Node 22 standard library only, no network.
